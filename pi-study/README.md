# Pi study profile

This is the isolated learning/studying Pi configuration. Launch it with `pistudy`, which sets `PI_CODING_AGENT_DIR` to this directory.

## Study-only resources

- `skills/teach/`
- `skills/visualize/`
- `skills/anki-cards/`
- `extensions/quiz.ts`
- `extensions/md-log.ts`
- `extensions/visual-tools/`
- `agents/researcher.md`
- `agents/mermaid-maker.md`
- `agents/svg-maker.md`

Common UI extensions and themes are loaded from the sibling `pi/` coding profile through `settings.json`. The PDF skill is also shared explicitly. Coding-only review and profiling skills are not loaded.

Authentication credentials are copied from `pi/` into ignored files in this directory. Sessions and installed package state remain profile-specific.
